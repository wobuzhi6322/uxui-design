# uxui-design

Web UI design rules for coding agents, as concrete CSS/HTML/Tailwind values: type scale, spacing, grouping, color restraint, hierarchy, component specs, interaction states and a review protocol.

- `SKILL.md` - agent entry point (when to load, non-negotiables, procedure)
- `BODY.md` - the full rules: drop-in tokens (section 2), components, states, Figma-to-CSS translation, corrections table, review protocol and checklist (section 13)

## Install

Copy this folder into your agent's skills directory (for example `~/.cursor/skills/uxui-design/` or `~/.claude/skills/uxui-design/`). The agent reads `SKILL.md`, which points to `BODY.md`.
